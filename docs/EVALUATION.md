# 实际验证结果（2026-10-12）

本轮使用 Windows、Python 3.12.14、规则决策替身与六个短虚构政策文档。没有真实模型调用、LLM Judge、真实支付或真实订单实验。

47 项 pytest 全部通过，包含业务分支、未确认/拒绝/越权零业务写入、并发重复确认、旧版本、过期、库存/订单/政策变化、超时重试、上下文白名单、伪造动作、HTTP 模型协议与失败计数、远程政策匹配验证、API/SSE，以及真实 Python 子进程退出和重启。MockTransport 的模型/远程检索测试属于模拟验证。

固定 30 条测试任务，同一输入、相同权限与执行器、每例独立数据库，分别跑 single/multi：

| 指标 | single | multi |
|---|---:|---:|
| 满足预期（含正确拒绝/等待） | 30/30 | 30/30 |
| 安全失败 / 重复业务记录 | 0 / 0 | 0 / 0 |
| 恢复样例符合预期 | 2/2 | 2/2 |
| 引用结构校验通过 | 30/30 | 30/30 |
| 中位总耗时（ms） | 384.10 | 459.60 |
| 决策调用（规则替身） | 208 | 405 |
| 真实模型 HTTP 调用 | 0 | 0 |

数据来自 [逐例测试报告](../reports/test_demo.json)。耗时含本地 SQLite、checkpoint、工具与新 Service 实例；是一次运行的观测，不是严谨统计显著性实验。safe/duplicate=0 只对这些人工预期与断言成立。引用指标包含无方案样例，不能解释为全部语义回答正确。

开发集 10 条，single/multi 各 10/10；[开发报告](../reports/dev_demo.json) 在最终测试前运行，不混入测试成绩。没有调参到多 Agent 更好。这个小集里规则决策的结果相同，多 Agent 的上下文分工和补查有展示价值，但额外决策及存储更贵。真实模型能否因独立上下文而受益仍未验证。

实际工程验证还包括：全新虚拟环境按 lock 离线安装、pip check、从复制的干净源码构建 wheel、从源码目录外导入已安装 wheel，完成登录/SSE/确认/业务落库，验证政策/演示 seed/static/评测数据已打包。运行环境不依赖旧 RAG 或个人磁盘路径。

无界面 Microsoft Edge + 已安装 Playwright 实际检查页面：确认前记录数 0、确认后完成、刷新恢复、40 个步骤事件、JavaScript 错误 0；截图保存在工作目录。浏览器检查属于真实本地页面验证，决策仍为规则替身。

失败和修复见 [FAILURES](FAILURES.md)。未验证：付费真实模型质量、原 RAG HTTP 桥接、向量语义检索、大规模并发、Linux/macOS、生产身份、真实用户业务与真实资金。已知第三方依赖弃用警告不影响本轮测试；未来升级需重跑兼容检查，不盲目更新。
