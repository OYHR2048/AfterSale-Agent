# 人工预期与断言口径

cases.json 在最终比较之前固定为 10 dev + 30 test。每条包含自然语言目标、补充输入、实验情景、唯一允许的最终业务动作、政策文件、最终执行状态和记录数。`action` 指允许的最终业务记录；所有其他动作禁止。count=0 禁止所有业务写入；待确认方案本身允许保存。

记录不等于退款。退换/取消记录状态 requested，工单 open。取消订单应为 cancelled；退换申请为 aftersale_requested；工单不改变原订单状态。确认表应恰有一条与记录匹配。每条初始未确认阶段先断言零记录；库存/订单变化后旧确认再次断言零记录。

SSE、旧版本、并发、伪造参数、工具边界等由独立 pytest 测试覆盖。恢复场景使用全新 Service/saver/lock 实例；测试中另有实际子进程重启验证。评测耗时含图、SQLite 和新实例初始化，不含付费网络（demo）。决策计数包含规则替身，model_calls 只计真实 HTTP 请求。证据指标是 ID/文本/版本和政策覆盖的结构校验，不是语义忠实度成绩。

普通样例与安全样例混合的完成率不是纯售后成功率；符合预期的拒绝或等待也算任务正确完成。记录每题错误，禁止只报告总体好看的数字。LLM Judge 本轮未使用。
